## 남은 문제와 다음 작업의 경계

1. 실기기 성능 저하가 미해결이다. 사용자는 소리 정상 출력을 확인했으므로 소리 미출력 문제를 새 과제로 만들지 않는다. 재현 시작 조건은 주인공 탱크 사격과 메뉴 애니메이션 재생이다. 당시 설치본은 전체Sprite CPU raster 도입 전이며 Trail만CPU였다. Debug -O0·CoreGraphics·음향 경로는 후보다. 원인을 확정하지 않았다. 최신Mac 오프스크린 측정도 메뉴/사격에서60Hz 예산을 넘었다. `build/frame-performance/manifest.json`을 보존했다. 사용자 우선순위가 바뀌기 전에는 성능 과제를 다시 앞세우지 않는다.
2. 원본 전체 동작·영상·음향 동등성, 연속 캠페인, 실기기 손기울임·성장·생명주기·장시간 성능은 남았다. 치트 검증 완료된10맵을 미검증이라고 되돌리지 않는다. 정상난이도 공략은 별도 범위다.
3. 실제게임3프레임 렌더 비교 최대RGB차이2/2/2로 픽셀일치는 미통과다. 원본 nil BaseParts의 이름별 최종경계·전체RNG/자식호출 순서도 미확정이다.
4. 원본 추가UI관측은 마지막 작업 때Mac 잠금으로 못했다. 새 작업에서 현재환경을 확인한다. 잠금을 우회하지 않는다. UI조작은 CUA를 사용한다. 시뮬레이터UI는 Xcode27 Device Hub(`com.apple.dt.Devices`)였다.

성공한검사를 이유없이 반복하거나 원본과의 작은차이를 무제한 새과제로 늘리지 않는다. 사용자가 지정한 다음 작업을 먼저 처리하고 확인한실패의 영향범위만 검사한다.
