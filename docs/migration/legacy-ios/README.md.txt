# iOS 기능 프로젝트

[HeavyMachRecovery](HeavyMachRecovery/README.md)는 Heavy Mach 1.13 원본 IPA를 ARM64 iOS 호환 실행기로 구동한다. Xcode 진입점은 `HeavyMachRecovery/ios/HeavyMachRecovery.xcodeproj`다.

허브의 [프로젝트 지도](../docs/project-workspace.md), [Git·문서 구조](../docs/project-layout.md)를 함께 따른다. 현재 이 디렉터리는 GameDev Git에서 관리한다.
