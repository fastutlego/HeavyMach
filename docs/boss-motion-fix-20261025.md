# 미션 3-5 항공기 조기 이동 수정 · 2026-10-25

## 사용자 관측과 대상 정정

사용자는 확장 화면에서 보스가 탱크 쪽으로 너무 빨리 접근하고 오른쪽 끝으로 잘 가지 않는다고 보고했다. 위치는 미션3의5번째 서브미션이며, 헬기형이 아닌 일러스트의 항공기형이라고 정정했다.

실제 연결은 `GlobalInfo::mapNumber({2,4}) → Stage14 → Boss05 → E_Boss02 → E_Boss02.png`다. `GameLoading_03E.jpg.png`도 대형 항공기 그림이다. 모델 이름과 이미지 번호는 같지 않다. `E_Boss05.png`는 다른 모델 Boss06의 부품이다. 앞선 헬기형 설명과 이미지 번호만으로 외형이 다르다고 한 중간 판단을 정정한다. 기존 측정 드라이버는 실제 Stage14/Boss05를 읽었으므로 측정 대상 자체는 사용자 항공기와 같다. machType1은 항공기와 헬기에 공통으로 쓰는 비행 이동 분기다.

## 원인과 변경

확장 시야 구현은 부품이 갑자기 나타나는 현상을 막으려고 보스를 미리 생성했다. 전선 잠금은 원작의 배치 좌표·500단위 접근·10단위 진행 샘플 조건으로 분리했지만, 미리 생성한 보스의 이동과 무기 AI는 즉시 실행했다. 이 때문에 원작480에서는 아직 생성되지 않은 항공기가 확장판에서는 먼저 이동했다.

`GameSession`에서 미리 준비한 맵 보스의 이동과 무기 AI를 기존 `bossEncounterActivated`에 연결했다. 발동 전에는 표시·피격·HP·처치 경로를 유지한다. 발동 때 원작 무기 초기 대기 시간의 시작 시각을 설정하고, 기존 난수로 정한 대기 길이는 유지한다. 재조립이나 추가 난수 호출은 없다. 활성 전 폭을480으로 전환해도 같은 접근 조건을 적용한다. 원본480으로 시작한 보스와 일반 적의 생성·활동은 기존 경로다.

적의 거리·속도 상수는 존재한다. 원작 `Enemy tick 0x13e04`, 상위 `GobHvMach tick 0x479c`, 생성 `processObjectRegen 0xcd00`의 기존 조사와 현행 소비 코드를 대조했다. 비행형은 플레이어+120보다 왼쪽이면 난수 검사 때 오른쪽 목표 속도를 선택하고, 별도의 난수 검사로 좌우 목표 속도±0.5를 선택한다. 화면 오른쪽 끝을 목표로 순찰하는 규칙은 없다. 이 수치를 화면 폭에 비례해 늘리지 않았다.

Stage14의 map.right는1459, 보스 전투 frontLine은1330이며 오른쪽 이동은 frontLine−30 부근에서 제한된다. 원본480과 확장 모두 같다. 한 tick의 위치 갱신으로1300을 소폭 넘는 기존 동작도 유지했다. 따라서 화면 오른쪽 끝까지 가지 않는 현상 전체를 새 오류로 판정하지 않는다. 이번에 확인하고 고친 오류는 접근 전 조기 이동·공격이다.

## 수정 전후 실행

로컬 증거: `build/boss-motion-20261025/`.

`audit.cpp`는 실제 원본 데이터·PNG 크기와 GameSession을 사용한다. 플레이어는x530, 항공기 배치는x1180이다. 내부 레벨99, 부품6/6/0, 무적·낙하복귀 사용, 사격 없음이다. 원본480과 확장694.857을 각각 시드11/42/101로30초 실행했다. 한 조건은 정지, 다른 조건은 처음300tick에 오른쪽 입력0.2를 주고 이후 정지했다. 비교값은30tick마다와 첫tick을 기록했다.

| 정지 조건 시드 | 수정 전 확장 항공기 최소X | 수정 후 최소·최대X |
|---|---:|---:|
| 11 | 943.228 | 1180 / 1180 |
| 42 | 707.354 | 1180 / 1180 |
| 101 | 945.155 | 1180 / 1180 |

수정 전 최대 왼쪽 이동은1180−707.354=472.646이다. 원본480은 같은 정지 조건에서 보스를 생성하지 않았다. 수정 후 확장은 시각적 준비만 하며 원작 접근 조건을 기다린다. 접근 조건에서는 두 폭 모두 전투 잠금1·frontLine1330을 유지하며 보스가 움직였다. 확장의 일반 적·시야·난수 소비 순서가 다르므로 전체 궤적의 프레임별 동일성을 주장하지 않는다.
