- 원본 생성 코드에 있는 플레이어 머리 위 HP 막대가 누락되어 복원했다. quake 적용 뒤 정수 좌표 변환·독립 화면 판정까지 회귀 검사했다. 수정 앱에서 노란 막대가 나타나는 것도 직접 확인했다. [근거](player-gauge.md).
- 게임→메뉴→게임에서 World 누적 시간이0으로 바뀌던 차이를 수정했다. 최초 실행0·메뉴 동안 정지·재진입 시간 유지 검사가 통과했다. [원본·검사](survival-audit.md).
- CTest11개 통과: `build/gauge-survival-ctest.log`. 시뮬레이터 빌드: `build/gauge-quake-simulator-build.log`. 일반 앱 실기기용 서명 제외 빌드: `build/gauge-clock-device-unsigned-build.log`. 물리 Air에는 추가 설치하지 않았다.
- 후속 원본 대조에서 일반 객체의 quake 화면 판정·조준 기준에도 누락을 발견해 수정했다. 위11개 검사 빌드는 그 추가 수정 전 결과다. 최종12개 검사와 두 플랫폼 빌드 성공은 아래 기록을 따른다.
- nil BaseParts의 원본 구조체 반환은 초기화되지 않은 buffer에 의존할 수 있다. 실제 원본 caller와 런타임 코드를 확인했으나 실행 중 stack값은 미관측이다. [남은 경계](nil-parts-boundary.md).

## 일반 카메라 연결 수정 후 검사

화면 흔들림을 bullet 충돌용 화면 판정, 적의 AI·타겟 화면 판정, 아이템·입자 화면 판정, 터치 조준 기준과 고정 지도 이미지에 반영했다. 수정 전 회귀 실패와 수정 후 Debug/ASan/UBSan 통과를 확인했다. [근거](camera-integration.md).

최종 CTest12개가 통과했다(`build/camera-integration-ctest.log`). 시뮬레이터 검증 앱과 일반 앱 iphoneos 서명 제외 빌드도 성공했다(`build/camera-integration-simulator-build.log`, `build/camera-integration-device-unsigned-build.log`). 이후 CUA에서 시뮬레이터 창을 찾지 못해 마지막 카메라 수정의 화면 재검사는 남았다. 앞선 HP 막대 실제 표시 확인과 구분한다.

## 보스48개 및 맵 진행 후속 결과

최신 코어에서 고정 입력으로 **48개 보스 배치를 모두 실제 처치**했다. 마지막 단일 실행은48/48, exit0이다. HP·지형·탄약·승패 규칙은 바꾸지 않았다. 초기 검증 조건과 성공 범위는 [보스 v6](boss-battles-v6.md)에 기록했다. 과거34/48 및47/48 결과는 실패 이력으로 보존한다.

정상 왼쪽 시작점부터41개 맵을 각각 진행한 첫 전체 검사는19클리어·21사망·1시간초과(exit1)다. 다음 스테이지15개와 미션 메뉴4개 전환 및 저장값을 확인했다. 단일 연속 캠페인은 아직 검사하지 않았다. [맵별 결과](stage-journeys.md). 이 검사와 후속 작업에는 물리 iPhone을 사용하지 않았다.

41개 중 원본 일반 진행으로 도달하는 맵은35개다. 최초 여정 검사의 일반 진행35개는19클리어·15사망·1시간초과다. 나머지6개는 데이터에 있지만 일반 nextStage가 연결하지 않는 mission index7의 직접 지정 검사이며 모두 사망했다.

## RGB565·빌드 구성 후속

알파 채널이 없는 원본 이미지16개의 RGB565 색 변환을 이미지 로딩 경로에 복원했다. 원본 RGBA679개는 새 변환을 건너뛴다. 695개 원본/파생 형식·해시는 `Resources/texture-formats.json`에 있다. 원본 및 파생 이미지 파일은 수정하지 않았다. [렌더 검토](render-fidelity-audit.md).

변환65536개 값의 검사와 독립 이미지 방향·채널·버퍼 수명 검사(ASan/UBSan)가 통과했다. 전체 CTest는 **13개 통과**(`build/texture-format-ctest.log`), simulator 검증 앱과 일반 iphoneos 서명 제외 빌드도 성공했다(`build/texture-format-simulator-build.log`, `build/texture-format-device-unsigned-build-retry.log`). 이 시점에 남았던 UIKit 보간/atlas 차이는 후속 [렌더 연결](sprite-native-integration.md)에서 수정·표본 검증했다. 전체 장면의 원본 출력 일치는 여전히 미검증이다. 실기기 추가 설치와 최신 UI 비교는 하지 않았다.

xcodegen 재생성 뒤 일반 앱 scheme이 없어 첫 iphoneos 빌드는65로 실패했다. 실패 로그 `build/texture-format-device-unsigned-build.log`를 보존했다. `iOS/project.yml`에 일반/검증 scheme을 명시하고 재생성해 두 target 분리를 확인한 뒤 재빌드했다. 일반 앱에는 HM_VALIDATION=0, 검증 앱에는1을 유지한다.

## 맵 여정 후속 원인 구분

Stage18의 첫 정지는 뒤에 남은 보스를 제외한 자동 조작과 원본 보스 이동 경계가 만든 결과였다. 후속 전환 정지는 하네스의 즉시 업그레이드 닫힘 호출에서 발생했다. 원본 닫힘 지연을 적용한 분리 검사가 전환을 통과했으므로 게임 코어를 변경하지 않았다.

최초19/41 결과는 같은 전략으로 모든 tick/EXP/RNG/저장값을 재현했다. 당시 실제 닫힘 지연을 사용하는 41맵 전체 전략은 **18클리어/23사망, exit1**이었다. 후속 selected-35 결과는 문서 상단에 별도로 기록했다. 분리된 Stage18 성공을 이 결과에 합산하지 않았다. 전체 미션 연속 성공과 원본 UI 동등성은 미검증이다. [증거와 전략별 한계](stage-journeys.md).
