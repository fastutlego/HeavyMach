# Android 앱 구현과 Galaxy 검사

2026-10-30. `develop`의 `d46e122a`에서 `feat/android-app`을 만들었다. Android 일반 앱과 치트 앱을 구현하고 Galaxy SM-S731N에 설치했다. 기존 Apple 소스·프로젝트·코어·자원 2,166개 파일의 해시는 작업 전후 같다. `develop`과 `main`에는 병합하지 않았다.

## 구현한 부분

| 범위 | Android 구현 |
|---|---|
| 전투·탄도·데미지·적·자동조준·미션 | 기존 `Sources/Core`를 그대로 NDK로 컴파일 |
| 메뉴·HUD·프레임 진행 | Apple 호스트의 상태·좌표·처리 순서를 Android C++로 이식 |
| 그래픽 | EGL·GLES 1.1. 원래 논리 좌표·블렌드·UV·RGB565 처리와 전체 화면 캔버스 유지 |
| 음향 | 같은 OpenAL Soft와 31종 음원. Android OpenSL 출력과 오디오 포커스 연결 |
| 입력 | 터치·가속도계·키보드·키 재배치. 치트 앱에는 조건 설정과 이동·점프·발사 버튼 추가 |
| HUD 편집 | 멈춤 메뉴에서 진입. 실전 화면·샘플 장면·드래그·적용·취소·초기화 |
| 저장 | 기존 저장 바이트 형식. 게임 이벤트에서 저장하고 HUD는 적용할 때 저장 |
| 중단·복귀 | 홈·잠금·포커스 상실 시 입력 해제와 일시정지. 복귀 후 직접 재개 |
| GPU 복구 | Surface·EGL 컨텍스트를 다시 만들고 GPU 자원을 복원. 게임 세션은 유지 |
| 자원 | 기존 게임 자원 800개와 검증 manifest를 APK 안에 포함 |

보스 구간에서는 자동조준 대상이 선택됐고 발사 10회 중 지정 표적 명중 1회가 기록됐다. 사격을 이어 가는 동안 게임 저장 횟수는 늘지 않았다. HUD를 드래그하는 동안에도 파일을 쓰지 않았고, 적용할 때 한 번 저장했다.

일반 앱은 실제 화면에서 타이틀→슬롯→모드→미션→전투로 진입했다. 점프·사격·멈춤 메뉴를 확인했다. APK의 패키지 분리·서명·16KB 파일 정렬·ELF 정렬 검사를 통과했다. 일반 APK에는 치트 명령 수신기가 없다.

## Galaxy 무선 설치

USB에서 디버깅을 승인한 Galaxy를 같은 LAN의 ADB TCP 연결로 연결했다. USB와 Wi-Fi의 기기 일련번호를 대조했다. 케이블을 뺀 뒤 일반·치트 APK를 다시 설치했고 일반 앱의 저장 파일이 바뀌지 않은 것을 비교했다. 최종 두 앱의 실행과 로그 수집을 마쳤고, 검사한 앱을 종료한 뒤 홈 화면으로 돌려놓았다.

이 과정에서 기존 ADB 서버만 `No route to host`를 반환했다. 휴대폰의 디버깅 포트와 새 TCP 연결은 정상이었다. 나흘 전부터 실행 중이던 서버를 한 번 재시작한 뒤 연결됐다. 이 확인 순서를 [Android 기기 실행 스킬](../.agents/skills/debug-heavymach-android/SKILL.md)에 기록했다.

`device.py`가 기기 선택·설치·실행·캡처·로그 수집·앱 종료·홈 복귀를 제공한다. Android 11 이상 무선 디버깅의 코드 페어링도 지원한다. 이번 기기 검사는 USB 승인 후 TCP 연결을 사용했다.

## 프레임·메모리·온도

Galaxy에서 보스 구간을 예열한 뒤 45초간 사격했다. SurfaceFlinger의 화면 표시 간격 2,763개를 수집했다. P90은 16ms 구간, P99와 최대값은 17ms 구간이었다. 33ms를 넘는 구간은 없었다. 수집 방법은 [Android 게임 프레임 측정 절차](https://developer.android.com/games/optimize/framerate)를 따랐다.

같은 구간의 PSS는 197,636→198,093KB, 네이티브 힙 할당량은 52,639→52,790KB였다. 배터리 온도는 32.3→32.4°C, 종료 시 Android thermal status는 0이었다. 15초 Perfetto trace도 저장했다. 장시간 메모리·발열 검사는 남아 있다.

## 검사 중 수정한 부분

- Android 창을 만들기 전에 인셋 제어기를 읽어 첫 실행이 종료됐다. 화면 생성 뒤에 전체 화면 설정을 적용했다.
- 움직이지 않은 손가락까지 매번 조준 이동으로 전달해 레이저 발사가 막혔다. 좌표가 바뀐 손가락만 MOVE로 전달했다. 수정 후 20종 발사를 다시 검사했다.
- 전체 EGL 컨텍스트 폐기 과정의 개별 FBO 삭제에서 에뮬레이터 드라이버가 종료됐다. 공유 객체가 없는 컨텍스트 전체를 폐기하고 새로 생성하도록 정리했다. 에뮬레이터와 Galaxy에서 같은 재생성 경로를 검사했다.
- 키보드의 최초 조준점이 근거리 터치 판정 안에 들어갔다. Android 최초 조준점을 탱크 앞쪽 160 단위로 잡았다. 원래 터치 판정과 무기 코드는 유지했다.
- 태블릿 크기로 바꾼 뒤 편집 화면의 위쪽 배경이 비었다. 일시정지 화면과 같은 배경 채우기를 HUD 편집에 적용했다.
- 치트 미션 전환 시 이전 멈춤 메뉴를 닫도록 연결했다. 치트 `JUMP` 버튼의 줄바꿈도 제거했다.
- 검사 도구가 이전 진단 JSON을 재사용할 수 있었다. 매 요청마다 새 파일만 읽도록 바꿨다. 테스트 시작 시 이전 보스 조건과 조준 모드도 초기화했다.

## 남은 확인

- 전체 캠페인의 실제 클리어·성장·결과 화면·서바이벌 장시간 플레이.
- Android 태블릿 실기기와 16KB 페이지 기기. 현재 Galaxy의 메모리 페이지는 4KB다.
- 확장 이미지 축소 결과의 Apple/Android 대조. Android의 area prefilter와 Apple의 CoreGraphics 축소 결과를 비교한다.
- 장시간 발열·메모리와 블루투스 오디오 장치 전환.
- 배포용 서명과 release APK. 지금 설치한 일반·치트 APK는 최적화한 debug 서명 빌드다.
