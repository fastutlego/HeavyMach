# 메뉴 재배치·배경 확장 적용 — 2026-10-25

## 구현한 범위

사용자가 승인한 imagegen 제작 계획을 실행했다. 내장 `image_gen`으로 타이틀 확장 후보A/B와 금속 메뉴 배경을 생성했다. 실제 원본 합성에서 A가 원본 왼쪽 광원·오른쪽 어두운 폐허에 더 가까워 A를 적용했다. B는 비교 후보로 보존했다. 원본 로고·문구·전차·슬롯 카드·수치·버튼은 다시 그리지 않았다.

- 타이틀: 높이320의 가변폭 캔버스. 생성 이미지의 왼쪽/오른쪽25%만 그린다. 가운데50%는 그리지 않으며 그 자리는 원본 Main_BG가 맡는다. 원본 카메라 이동·회전·확대와 같은 변환으로 좌우를 움직인다.
- 경계: 생성 이미지를 단순 연결하면 수직 이음새가 드러났다. 원본 사각형 **바깥20논리픽셀**에서 원본 가장자리 일부를 반사하고 새 배경으로 점차 전환한다. 원본 내부 픽셀에 흐림·변형·페이드를 적용하지 않는다. GL 고정 기능 합성만 추가했고 매 프레임 bitmap을 만들지 않는다. 임의의 완벽한 화풍 일치를 주장하지 않으며 실제 합성 캡처로 판단한다.
- 슬롯: 배경 한 장에 포함된 제목·카드 틀·설명을 원본 텍스처의 clip으로 분리해 배치한다. 탱크 미리보기·숫자·선택 테두리·터치 영역이 같은 이동량을 쓴다. 좌우 안전영역 사이에 세 카드를 벌리고 삭제/확인 버튼을 양쪽 하단에 둔다. 카드·버튼 및 제목·카드 겹침을 수정했다.
- 모드·미션 선택: 원본 메뉴 묶음을 안전영역 중앙에 배치하고 추가 바깥 공간에 금속 배경을 표시한다. 미션 확인 버튼은 하단 안전영역을 피한다. 이 두 화면은 슬롯처럼 전체 내부 요소를 재설계하지 않았다.
- 로딩 셔터: 메뉴 전환의 바깥 영역에도 원본 셔터를 반복 합성한다. 원본 타이밍과 게임 전환 순서는 그대로다.
- 치트 방향 버튼: 타이틀·선택 화면에서 숨기고 전투 화면에서 표시한다. 제목을 가리지 않는다.
- 원본480 모드와 전투 월드·무기·진행·저장 규칙은 유지한다. 화면 재배치 중 누른 메뉴 버튼은 취소한다.

## 자원과 재현

- 후보: `Art/Candidates/title-20261025/title-a.png`, `title-b.png`.
- 최종 프롬프트·도구·채택 이유·원본/생성물 SHA: `Art/generation-20261025.json`.
- 각 생성 이미지2172×724, RGB PNG다. 현재 로더의 POT/RGB565 정책으로 각각4096×1024×2바이트(8MiB)의 텍스처 저장량이 필요하다. 이는 포맷으로 계산한 값이며 Instruments의 프로세스 메모리 측정값이 아니다.
- `Extensions` 번들 폴더로 원본 `OriginalImages`와 분리했다. 화면 scope에서 미리 로드하고 다른 화면으로 넘어갈 때 해제한다. 반복 렌더에서 decodeCount 증가0, 업로드 후 decodedBytes0을 검사했다.
- IPA 원본 이미지695개와 현재 OriginalImages695개의 SHA256이 모두 일치한다. 근거: `build/menu-extension-20261025/original-image-preservation.json`.

## 검사

전용 iPhone Air Simulator(iOS26.5)에서 원작480×320, Air912×420, Pro Max956×440의 View 크기와 좌/우 safeArea를 조합했다. 실제 Pro Max 기기 검사나 OS 물리 회전 검사가 아니다.

- 관련27개 검사 통과: 새 메뉴·타이틀 합성/터치, 기존 메뉴9개, GL12개, 자원3개, 전체20무기360조건, 결과 일러스트15개×3화면.
- 후속 선택 경로 검사 통과: 세 슬롯 선택 → 삭제 확인 취소 → 모드 선택 → 미션 선택 → 실제 게임 세션 시작. 두 가로 safeArea와 세 화면 크기에서 실행했다. 실제 GL 캡처24개를 남겼다.
- 원본 중앙 비교는 기존 GL/결과 이미지 검사와 같은 색상 채널 차이 최대1 기준이다. 최초 신규 검사는0을 요구해 최대1 차이에서 실패했다. 같은 텍스처·변환과 dithering을 확인한 진단 기록도 보존했다. 원본 파일 불변은 별도 SHA 비교로 확인했다. 제품의 dithering 설정과 기존 GL 검사 기준은 변경하지 않았다.
- 최초 실패, 겹침 수정 전후, 후보B의 경계, 최종 캡처를 삭제하지 않았다. `initial`, `revised`, `diagnostic`, `edges`, `texture-oracle`, `composition`, `final`, `navigation`의 로그/xcresult가 `build/menu-extension-20261025/`에 있다. 첫 실패 뒤 수분 소요된 진단 수집만 종료했고 시험 실패는 보존했다. 이후 실행은 긴 sysdiagnose 수집을 끄고 시험 자체는 그대로 수행했다.

## 추가 빌드·반복 프레임 결과

일반 앱 iPhone ARM64 미서명 빌드 성공. 치트 앱 iPhone 서명 빌드·설치는 성공했다. 일반 앱의 이번 버전 실기기 설치는 아직 하지 않았다.
