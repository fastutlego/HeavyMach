# HUD 이벤트 순서 수정

2026-10-24. HP 바늘과 강화 창을 draw에서 갱신하여 원본보다 늦게 처리하던 차이를 수정했다. REA `0x17620`, `0x1762c`, `0x16a98`, `0x17c4c`, `0x161d0`에 따라 World 이벤트를 HUD tick 전에 전달한다. 같은 재장전 값도 기어 속도를 다시 설정한다. 메뉴 버튼도 즉시 열림·닫힘 상태를 설정하고 원본 sound0을 사용한다.

`GameMain.setScreen_Game0x3a1c`에 따라 게임 진입 마지막에 pause를 해제한다. 잔여 EXP로 openMap 중 레벨업 창이 열리는 경우에도 원본의 마지막 unpause를 유지한다. Core의 맵 전환 pause 계약은 바꾸지 않았다.

실제 HMGameView를 사용하는 iOS 검사에서 수정 전 3개 검사·7개 assertion 실패를 확보했다. 수정 후 HP·메뉴·강화·잔여 EXP 진입·시간제 효과 연결과 HUD 독립 검사를 합쳐 9/9 통과했다. CTest17/17도 통과했다. 원본은 정적 역분석 근거이며 이 검사 자체가 원본 실행 비교는 아니다. 로그와 해시는 `build/hud-event-order/manifest.json`을 따른다.

같은 selected-35 조작 조건으로 새35맵 실행을 완료했다. **25클리어·10사망·0시간초과, exit1**이다. 다음 맵 진입20개, 미션 메뉴 요청5개다. Stage06/17은 이번 실행에서 클리어했다. 이전23클리어 기록과 합산하지 않는다. 초기 등급6·원본 유한 탄약·독립 시작 조건이며 전투 중 회복·보충·워프는 없다.34회 강화 확인과34회 닫힘 callback을 거쳤다. 연속 캠페인·실제 메뉴 터치·원본 동시 실행 비교는 아니다.

실패 맵은 Stage16/21/22/23/24/31/32/33/34/35다. 자동 조작의 사망을 제품 결함으로 단정하지 않는다. 일반 iPhone용 서명 제외 빌드도 통과했다. 수정 앱을 폰에 추가 설치하지 않았다.

## 재진입 HUD 유지 후속

이미 확인한 HUD 재생성 차이까지 같은 수정 범위에서 처리했다. 원본 `0x2ecc`의 GuiGame은 화면·슬롯 변경 때 재생성되지 않고, 숨겨진 상태에서도 `0x161d0` tick을 받는다. `0x151a0`은 HP 현재값·목적값을0으로 시작한다. 복원본도 같은HUD를 유지하고 메뉴·타이틀에서 tick하며, 최초HP 목적값을0으로 맞췄다. 처음 게임에 들어갈 때는 실제 HP 이벤트가 목적값을 설정한다.

수정 전 실제 GameView 검사5개 중1개에서8개 assertion 실패가 발생했다. 수정 후 관련 iOS검사10/10과 일반 iPhone 서명 제외 빌드가 통과했다. 첫 단일selector실행은0개 검사여서 증거로 세지 않는다. `build/hud-persistence/manifest.json`에 소스·로그·보존 앱 해시를 기록했다.

코어·맵 검사기는 바꾸지 않았다. 앞선CTest17/17과35맵25클리어는 해당 범위의 기존 증거로 재사용하며 이번에 다시 실행한 결과라고 하지 않는다. 물리기기에 추가 설치하지 않았다. 사용자 요청대로 새 과제·성능 수정·추가 원본 조사를 진행하지 않는다. 전체 원본 동등성은 미완료다.
