# 자동조준 상태 안내 계획

HUD 배치 편집과 별도 과제(HM-AIM-VIS)다. 현재는 표시 방법을 정리한 단계다. 기존 자동조준 버튼을 옮기는 작업은 [HUD 편집](hud-improvement-plan-20261028.md)에서 진행한다.

## 상태별 표시


표시만 보강한다. 표적 선택·전환·해제, 포신 조정, 탄속·분산·피해·발사 판정은 현재 코드를 유지한다.

| 실제 상태 | 제안할 표시 |
|---|---|
| 수동 모드 | A 버튼의 꺼진 모습 유지. 별도 조준 상태 문구 숨김 |
| 자동 모드, 대상 없음 | A 버튼 옆 작은 상태판에 `NO TARGET` |
| 대상 있음, 포신 조정 중 | `TRACK`와 기존 표적 테두리 |
| 현재 발사 조건 충족 | `LOCKED`와 기존 표적 테두리. 포신 조정과 발사 조건 충족을 표시 |
| 현재 발사 조건 미충족 | `BLOCKED`. 탄도 해를 찾지 못한 경우와 경로가 막힌 경우를 함께 포함 |
| 화면 밖 대상 | 안전영역 가장자리에 방향 화살표와 작은 표적 기호. 상태판은 계속 표시 |
| 화면 안이지만 지형 뒤에 가려 보이지 않는 대상 | 대상 위치의 테두리와 연결선을 지형 위에 표시. 발사 가능 상태와 따로 표현 |

현재 `AimStatus::blocked`에는 탄도 해가 없는 경우도 포함된다. 이것을 전부 ‘지형에 가림’이라고 표시하면 잘못된 안내다. 상태판은 기존 상태값을 그대로 읽고, 지형 가림 표현이 필요할 때는 표시용으로 지형과 표적의 겹침을 검사한다. 이 값은 조준·사격 로직에 전달하지 않는다.

상태판은 기존 금속 받침·노란 기호·스텐실 글자에 맞춘다. 화면 밖 화살표는 HUD 버튼과 겹치지 않는 가장자리를 찾는다. 색과 함께 글자·형태를 사용하며 깜빡임은 표적 획득 순간에만 짧게 준다. 먼저 대상 없음·화면 밖·발사 불가 세 장면의 실제 크기 시안을 비교한다.

## 구현 순서

대상 없음·화면 밖·발사 불가 장면의 실제 크기 시안을 먼저 비교한다. 이후 표시 코드만 연결하고 대상 격파·교체·뒤로 이동·지형 가림·화면 이탈을 검사한다.
