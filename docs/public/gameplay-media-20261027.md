# 플레이 영상에서 고른 이미지와 클립

두 영상에서 이미지 8장과 클립 3개를 골랐다. 대표 이미지로는 **01 자동조준 표적**을 추천한다. 탱크·적·사격·조준 표시·조작 버튼을 한 번에 볼 수 있다. 밝은 배경을 쓰고 싶다면 **02 점프와 사격**이 적합하다.

| 용도 | 권장 자료 | 설명 |

| GitHub 플레이 소개 | 02 점프, 03 무기 선택, 07 항공기 | 서로 다른 기능을 한 장씩 설명한다. |

## 원본과 판독 범위

| 원본 | 길이 | 영상에서 확인한 내용 |
|---|---|---|
| V1 · 10월 25일 19:38:32 | 2분 58.853초 | 미션 5-3 전투, 무기 목록, 업그레이드, 클리어, 5-4 시작 |
| V2 · 10월 27일 19:39:44 | 2분 4.050초 | 미션 3-4 전투, 자동조준 상태 표시, 항공기 편대 |

전체 구간을 약 4초 간격의 76개 프레임으로 훑고, 후보 6개 구간은 0.5초 간격으로 다시 봤다. 이미지는 회전 정보를 적용한 2736×1260 원본 크기다. 화면을 자르거나 게임 위에 설명을 합성하지 않았다. 영상 왼쪽의 검은 타원도 원본에 들어 있다. 클립은 원래 속도와 음향을 유지한 H.264/AAC다.

촬영 기종·앱 종류·빌드 번호는 영상만으로 특정하지 않았다. 두 녹화본은 UI와 미션이 달라 수정 전후 비교로 쓰지 않는다. 자동조준 ON/OFF 조작, 모든 무기, iPad·Mac 조작을 보여주는 자료는 이번 후보에 없다. 이 자료로 프레임률·발열·입력 지연을 측정하지 않았다.

## 고르지 않은 장면

- 미션 선택 직후와 클리어 직전의 전환 중 화면: 글자와 그림이 겹치는 순간이 있어 대표 컷에서 제외했다.
- 폭발이 탱크나 기체를 크게 가리는 순간: 공격 효과용 후보와 구분했다. 기체 소개에는 외형을 읽을 수 있는 컷을 쓴다.
- 같은 무기·배경이 반복되는 전투: 이미 고른 컷과 겹치면 제외했다.
- 10월 27일 영상의 마지막 구간: 클리어 화면이 나오기 전에 녹화가 끝나므로 클리어 장면으로 쓰지 않았다.

## Sass 인계

이미지 ID, 캡션, 대체 텍스트, 타임코드는 `media-scenes.json`에 함께 있다. Sass 세션은 필요한 파일과 해당 항목을 가져가면 된다. 원본 영상은 Git에서 제외했고 파생 이미지·클립과 출처 명세를 저장소에 보관한다. 원본 자료의 위치와 다시 추출하는 명령은 미디어 폴더의 README에 있다.
