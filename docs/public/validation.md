Simulator의 GPU 경로는 실제 기기와 다르다. 위 소프트웨어 렌더러 시간을 iPhone·iPad GPU 시간으로 환산하지 않는다. 사용자 체감과 프레임 처리시간 검사는 서로 다른 결과이므로 함께 남겼다.

Mac 전체 화면은 OS의 3840×2160 캡처에서 네 가장자리까지 게임이 표시됨을 확인했다. CUA 창 캡처에 보인 흰 여백은 실제 디스플레이 캡처에 없었다. [계측 JSON](../evidence/apple-platform-performance-20261026.json), [전체 화면 JSON](../evidence/mac-fullscreen-capture-20261027.json)

## 설치·무선 디버깅

일반·치트 앱을 iPhone·iPad에 각각 설치했다. 케이블을 분리한 상태의 기기 연결·설치·실행·LLDB 연결도 확인했다. iPad에서는 무선 검사 8개와 시작 구간 CPU 21.716초 기록을 남겼다. iPhone 무선 XCTest·Instruments 전체 실행과 재부팅 후 반복 검사는 남아 있다.

## 문서·미디어 확인

현재 자원 검사에서 빌드·검사 입력 1,482개의 SHA-256이 일치했다. 플레이 그림 8장과 MP4 3개는 사용자 영상에서 추출했고, GIF 2개는 같은 장면의 짧은 구간이다. 원본 파일 해시·시간·출력 해시는 [장면 명세](media/gameplay-20261027/media-scenes.json)에 있다. 촬영 기종·앱 종류·빌드 번호는 제공되지 않았다.

## 남은 검사

- 표시시간: iPhone 메뉴 기준 초과와 iPhone·iPad 전체 suite의 해당 실패 재현·원인 분리.
- 장시간: 이동·점프·전투·미션 전환을 포함한 발열·전력·메모리 변화.
- 입력: 실제 Bluetooth·USB 키보드 연결, 분리·재연결·키 유지·터치 병용.
- 난도: 추가 항공기가 등장하는 전체 미션의 탄약·피해·클리어 난도.
- 무선: iPhone XCTest·Instruments, 두 기기의 재부팅 후 반복 설치·디버깅.
