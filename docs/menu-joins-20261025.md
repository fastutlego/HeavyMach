# 모드·미션 배경 연결과 타이틀 검은줄 수정

사용자 요청: 모드/미션 선택의 좌우 생성 배경을 가운데 원본과 연결되게 수정하고 치트 앱에서 재검사한다. 작업 중 타이틀 양쪽의 검은줄도 보고되어 같은 변경에 포함했다.

## 변경

- 공통 금속 그림을 쓰던 모드/미션 배경을 각각 원본 `SelMode_BG.png`, `SelMission_BG.png`를 참조한 별도 outpaint로 교체했다. 철판·레일의 높이와 밝기를 각 원본에 맞췄다.
- 내장 imagegen으로 만든 `Art/Extensions/ModeWide.png`, `MissionWide.png`의 바깥 사분면만 표시한다. 가운데 생성 그림은 사용하지 않는다. 원본 가운데 그림과 버튼/입력 위치를 유지했다. 경계 바깥24논리단위에는 원본 가장자리 반사/페이드를 적용했다.
- 타이틀 검은줄은 비정수 위치·확대·회전에서 LINEAR 필터가 원본 그림 바깥의 검정 POT 여백을 읽는 문제였다. 원본480은 이 경로를 유지하되, 확장 타이틀/모드/미션 배경은 가장자리 반 texel 영역의 UV만 유효한 가장자리 색에 고정한다. 중앙 UV·그림 크기·카메라 움직임은 유지한다.
- 배경 한 장을9개 영역/54정점으로 그리되 draw call은1회다. 새 이미지 디코딩·파일 읽기·텍스처 업로드를 프레임마다 추가하지 않았다. 원본 PNG와 일반 sprite의 POT/LINEAR/REPEAT 동작을 바꾸지 않았다.
- 생성 이미지 각각2172×724, 기존 포맷 기준8MiB다. 화면에 해당하는1개만 scope에 준비한다. 기존 공통 메뉴 배경도 같은8MiB였으므로 각 화면의 확장 텍스처 저장량은 같다. Instruments 측정값이 아닌 포맷 계산이다.
- 프롬프트·도구·참조·SHA는 `Art/menu-joins-20261025.json`에 기록했다.

## 검사

- Simulator iOS26.5: 관련26/26 통과. GL13개(새 검은줄 회귀1개 포함), 메뉴9개, 자원3개, 실제 렌더/선택 경로1개다.
- 물리 iPhone Air PaleMirror iOS27.0.1: 같은26/26 통과. 원작480·Air·Pro Max View 크기와 양쪽 safeArea에서 타이틀/슬롯/모드/미션 렌더, 모드 전환, 미션 확정, 실제 게임 세션 시작을 검사했다. 물리 Pro Max 기기 검사나 손으로 회전한 검사는 아니다.
- 새 GL 회귀 검사는 흰480×320 텍스처를 비정수 위치/배율/회전3조건으로 그렸다. 기존 경로의 최소 밝기는153~204, 수정 경로는 모든 조건255였다. 원인 재현 대조군을 검사 안에 유지한다. 기존12개 GL 원본 기준도 모두 통과했다.
- 원본 중앙 비교는 기존 최대 채널 차이1 기준을 유지한다. 전체 화면의 미감 평가는 실제 GL 캡처로 별도 확인했다. 초기 단일 경계 열 RGB 차이는 원본 가장자리 보간과 좌표 반올림의 영향을 받아 연결 품질 통과 기준으로 쓰지 않았다. 기록은 보존했다.
- 일반 앱 ARM64 미서명 빌드 성공. 치트 앱 Xcode GUI 서명 빌드·서명 검증·실기기 설치·실행 성공. 설치 전 Documents 백업 보존. 일반 앱의 이번 수정본은 설치하지 않았다.
- Device Hub의 실제 PaleMirror 화면에서 타이틀의 검은선 제거, 슬롯 확인, 서바이벌 선택 강조→시나리오 재선택→미션 진입을 직접 관측했다. 수정한 모드/미션 배경을 확인하고 폰을 미션 선택 화면에 남겼다. GUI 관측과 위 자동 검사를 구분한다.

## 증거

- `build/menu-joins-20261025/first.xcresult`, `physical.xcresult`: 메뉴 생성 배경 교체 후13/13. 검은줄 수정 전이다.
- `seams.xcresult`, `physical-final.xcresult`: 검은줄 수정 포함 최종26/26. 같은 폴더의 로그에 `HM_JOIN_EDGE` 재현/수정 수치를 기록했다.
- `final-captures/`, `physical-captures/`: 각각 실제 GL 캡처와 manifest. `pixel-comparison.json`은 최초 메뉴 수정 전후 비교다.
- `normal-final.log`: 일반 앱 최종 빌드. 실기기 설치: `build/device-validation-runs/20261025T095320.295514Z/summary.json`.
- 설치 실행 파일 SHA256: `50ef70f6c30a5d6e1b702e75f14a7645250e03252d0d3f07be56418ef034d553`; debug dylib: `698103d789360bb4286195587252bcb0a2293623c5de424e192c0f57ae366313`.

이번 변경의 장시간 GPU/발열 측정은 하지 않았다. 기존 전투·무기 수치는 수정하지 않았으며 이전 전체 무기 검증을 재사용한다.
