# 보고 자료 보존 계약

- 원문 보고는 제목·문단·순서·문장·문장부호를 보존하고 요청 원문 전체를 제공한다. 요약·윤문·번역·발췌 권한으로 해석하지 않는다.
- 원문·수정 후보·승인본을 구분하고 요청된 의견은 별도 표시한다. 원고와 이미지가 함께 요청되면 대응 관계를 같은 페이지에서 확인할 수 있게 한다.
- 이미지는 실제 생성·승인 파일을 사용한다. 보고만을 이유로 다시 만들거나 편집하지 않는다. OG 카드도 대상별 원본과 버전을 대조한다.
- 비율을 보존하고 잘리지 않게 표시하며 원본 크기로 열 수 있게 한다. 요청된 이미지 수와 파일·호수·버전 대응을 확인한다.
- 이미지 바이트를 페이지와 함께 보존하거나 검증된 지속 URL을 쓴다. 로컬 경로·임시 서버·만료 서명 URL을 배포 원본으로 쓰지 않는다.
- 누락·생성 실패는 명시하며 다른 이미지로 메우지 않는다. 제공 범위 밖의 개인 자료·시민 정보·계정·토큰·환경 파일을 제외한다.
- 본인용 비공개 검수 제공은 보고 요청 범위에 포함되지만 전체 공개·타인 공유로 확대하지 않는다.
- 빌드·공식 배포 상태·접근 범위·자료 전체성을 확인하고 링크를 전달한다. 실패하면 실제 원인·미배포 상태를 알리며 원본과 기존 Site를 유지한다.
