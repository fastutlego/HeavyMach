사용자가 요청한 원고와 이미지의 버전·호수·대응을 확인한다. `references/materials.md`의 자료 보존 원칙을 필요한 경우 읽는다. 원문 재작성이나 이미지 재생성은 별도 요청 범위다.

최신 지정 형식을 따른다. 지정이 없으면 기존 비공개 Sites 검수 페이지를 재사용한다. 실제 Sites 도구가 있으면 현재 도구 스키마로 작업하고 없으면 사용 가능한 전달 방식과 한계를 알린다. 공급자 설치나 unavailable 스킬은 작업 중단 조건이 아니다.

원문 전체·문단 순서·이미지 수량/비율/출처를 결과와 대조한다. 실제 배포 요청을 완료했으면 성공 상태·비공개 접근·실제 URL을 확인한다. 로컬 결과를 배포 완료로 부르지 않는다.
