# sass-review-publication

작업에 해당하는 [도메인 문서](../../../governance/REVIEW_MATERIALS.md)만 읽는다.

공유할 실제 자료와 대상·노출 범위를 확인한다. 원본 이미지와 문서의 내용·비율·출처를 보존하고 비밀정보를 제외한다. 사용자가 지정한 게시 도구와 기존 배포 경로를 사용한다. Sites가 요청되면 현재 제공된 Sites 스킬을 따른다. 생성한 파일과 실제 접근 가능한 게시 결과를 구분해 확인한다. 요청하지 않은 별도 사이트나 저장소를 만들지 않는다.

새 문안을 작성하거나 수정할 때 상투적인 역량 전이 문구, 근거 없는 연결 문장, 추상적인 기여 약속을 금지한다. “X 경험을 Y 업무에 연결하겠습니다”, “이 경험을 바탕으로 기여하겠습니다”처럼 관련성이나 기여를 선언하는 문장을 붙이지 않는다. 관련성을 설명해야 하면 공통된 문제와 실제 수행 행동, 이번 작업에 적용할 구체적인 방법을 쓴다. 추가할 사실이나 방법이 없으면 문장을 삭제한다. 같은 뜻을 다른 추상어로 바꾸지 않는다. 사용자 원문·직접 인용은 보존한다.

허위 구체성, 상투적 절차 나열, 요구사항 재진술, 해결 방법 없는 요구사항 재진술을 금지한다. 작업량·기존 코드·의존성 등 산정 근거 없이 주차·기간·수치·세부 작업을 확정하지 않는다. “분석 → 개발 → 테스트 → 배포” 같은 일반 절차나 기술명·점검 항목의 나열로 제안을 채우지 않는다. 공고의 요구사항을 “구현하겠습니다·연동하겠습니다·점검하겠습니다”로 바꾸어 반복하지 않는다. 제안에는 확인한 문제와 그에 대한 구체적인 해결 방법·선택 이유를 쓴다. 근거가 없으면 구체성을 꾸미지 말고 해당 문장을 뺀다. 원문 인용과 내부 요구사항 목록은 보존하되 이를 해결안으로 내세우지 않는다.

작업 방법과 사실 보고는 루트 AGENTS.md를 따른다.
