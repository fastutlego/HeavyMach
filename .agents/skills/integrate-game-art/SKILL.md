# 게임 아트 연결

HeavyMach 아트는 `docs/canonical.md`, `docs/game-design.md`, `docs/rendering-policy.md`, `docs/coordinate-policy.md`와 `Art/generation-20261025.json`·`Art/menu-joins-20261025.json`를 읽고 원본 중앙 에셋·좌우 확장·실제 앱 합성을 대조한다. 이미지 생성이 필요하면 현재 제공된 imagegen 스킬을 사용한다.

원본 이미지는 수정하지 않고 별도 파생 에셋을 만든다. 변경한 메뉴·게임 화면의 실제 합성과 터치 위치를 검증하고, 결과는 이 저장소의 present-game-artifacts와 docs/report-site.md를 따른다.

분리 전 Unity 절차는 [보존 원문](references/unity-original.md)에 있다.

## 실물 기체를 바탕으로 만드는 유닛

사용자가 실제 기종을 지정하면 기체의 기본 형상을 유지한다. 기존 게임의 색조·질감·명암을 맞추라는 지시를 비례·날개·꼬리·흡입구의 임의 재설계로 확대하지 않는다. 별도 사실적 이미지 생성 스킬을 설치할 필요 없이 현재 imagegen을 사용한다.

- 해당 기종과 형식을 확인하고 실제 측면 사진·도면을 형태 참조로 제공한다. 기존 게임 유닛은 색조·질감·명암 참조로 따로 지정한다.
- 동체 길이/높이, 기수, 조종석, 주익·꼬리날개의 수와 위치, 흡입구·배기구 위치를 유지하도록 프롬프트에 명시한다. 사용자가 요청하지 않은 장갑화·단축·과장된 비례를 넣지 않는다.
- 생성 후 실제 참조와 위 항목을 대조한다. 원본 크기와 게임 표시 크기에서 모두 확인한다. 기체가 다른 형태로 바뀌면 다시 생성하거나 해당 부위만 수정한다.
- 기체 그림과 엔진 효과는 분리한다. 실물 구조와 게임용 효과 표현을 구분하고, 시안의 불꽃까지 충돌 영역으로 사용하지 않는다.
- 2026-10-27 VTOL 첫 시안은 사용자가 실제 모델과 다른 형태를 지적했다. 참고 이력으로 보존하며 최종 에셋으로 채택하지 않는다.
