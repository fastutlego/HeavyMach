# HeavyMach 작업 위치

이 저장소 루트가 HeavyMach 프로젝트다. AGENTS.md와 docs/canonical.md에서 시작한다. 원본 호환판은 Compatibility/다. Unity 소스는 이 저장소에서 변경하지 않는다. 브랜치 규칙은 docs/repository-management.md를 따른다.

- Candidate·Sass는 비공개 프로젝트다. 해당 프로젝트의 내부 문서·소스·Git 조사 자료와 이를 참고하는 원고 준비 자료는 HeavyMach 공개 Git 저장소에 추가하지 않는다. 로컬 내부 자료를 별도로 보관하며, 공개할 완성 원고와 내부 근거 자료를 구분한다.
